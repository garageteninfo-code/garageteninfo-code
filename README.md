# HARVEST（ハーベスト）

小さな会社・下請け・子会社のための、無料の道具を作っています（どれも試作です）。

| 道具 | できること | 使い方 |
|---|---|---|
| [ふせじ番](https://garageteninfo-code.github.io/fusejiban/) | AI に貼る前に、個人情報・鍵を伏せ字にする | ブラウザで開くだけ |
| [名寄せ番](https://garageteninfo-code.github.io/nayoseban/) | 名簿の検索・同じ人の候補・入金の消し込みの手伝い | ブラウザで開くだけ |
| [鍵の預け番](https://garageteninfo-code.github.io/kaginoazukeban/) | 社長だけが知る鍵を、紙に分けて預ける | ブラウザで開くだけ |
| [戻せる番](https://github.com/garageteninfo-code/modoseruban) | バックアップが戻せるかを確かめ、月次の報告にする | Windows・ダブルクリック |
| [使いすぎ番](https://github.com/garageteninfo-code/tsukaisugiban) | AI の使いすぎ・情報の出しすぎを、送る前に止める | Windows・ダブルクリック |
| [手抜き番](https://github.com/garageteninfo-code/tenukiban) | AI が書いたコードの手抜きを見張る | 開発者向け |
| [配信番](https://github.com/garageteninfo-code/haishinban) | Windows アプリを少しずつ配り、まずければ戻す | 開発者向け |

- ブラウザで使う3つは、開いたあと外に何も送りません。
